# E-Commerce Operations & Customer Intelligence

An end-to-end data analytics and business intelligence project focused on understanding e-commerce sales performance, delivery operations, seller efficiency, and customer satisfaction.

## Project Overview

This project aims to transform raw e-commerce data into actionable business insights using Python, SQL, Excel, and Power BI.

The analysis uses the Brazilian E-Commerce Public Dataset by Olist.

## Objectives

- Analyze revenue and sales performance.
- Identify delivery delays and logistics bottlenecks.
- Evaluate seller performance.
- Understand customer satisfaction and review patterns.
- Identify factors associated with poor customer experiences.
- Develop interactive business intelligence dashboards.

## Technology Stack

- Python – Pandas, NumPy, Matplotlib, Seaborn
- SQL – Data querying, joins, CTEs, window functions
- Excel – Pivot tables and exploratory analysis
- Power BI – Interactive dashboards and DAX
